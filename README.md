# pycast-mute-spot
python script based using pychromecast to mute Spotify during ads on Cast devices and skip some news briefing ads

- Needs Python.
- Requires https://github.com/home-assistant-libs/pychromecast to run. 
- Edit CAST_NAME to the friendly name of your cast device.
  - Can specify on launch ```python spotifyadmute_simple_listener.py --cast 'My G Home Name'```
- Run the script
- Play content on device
